# Процессы

## Состав
- Список процессов
- Время выполнения
## Алгоритм:
- Удаляем первый столбец
  ![[Pasted image 20260218193843.png]]
- Разбиваем процессы (Данные->Текст по столбцам)
  ![[Pasted image 20260218193927.png]]
- Выделяем блоки: разделенные процессы/столько же столбцов доп./результат
  ![[Pasted image 20260218193948.png]]
- ВПР(Начало процессов(C1); Вся таблица(с $); номер столбца с ответами; 0)
- Результат: (=макс(столбцы ВПР) + Время выполнения самого процесса))
  ![[Pasted image 20260218194003.png]]
- В номерах заменяем пустые клеточки на 0
- В таблице под ячейками А(где номера процессов) и G(ответы) ставим 0
  ![[Pasted image 20260218194032.png]]
- Решаем условие задачи
